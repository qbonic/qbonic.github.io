# Qbonic Website — 100% In-Browser Interactive Reporting Landing Page

This repository contains the official landing page and Beta Testing Registration platform for **Qbonic**, an in-browser interactive data reporting application.

## 🚀 Key Features

- **Zero Build / Zero Dependency**: Pure HTML5, Vanilla CSS3, and ES6 JavaScript. No `npm`, `package.json`, or node server required.
- **GitHub Pages Ready**: Host for free directly on GitHub Pages.
- **Custom Domain Ready**: Compatible with custom domain assignment via GitHub Pages settings or `CNAME`.
- **Interactive Sandbox Simulator**: Live in-browser data simulator with dataset switching (E-Commerce, SaaS ARR, Marketing Ads), SVG trend chart rendering, and AI Voice Copilot action simulation.
- **Beta Sign-Up Platform**: Interactive form validation, local storage persistence, and early access ticket generator.
- **Mobile First & Responsive**: Touch-optimized menu drawer, adaptive SVG graphs, and fluid typography.

## 🌐 Deploying to GitHub Pages with Custom Domain

1. Create a public or private repository named `qbonic-website` on GitHub.
2. Push all files (`index.html`, `style.css`, `app.js`) to the `main` branch.
3. In GitHub repository settings:
   - Go to **Pages** -> **Branch**: Select `main` -> `/ (root)` -> Save.
4. Under **Custom domain**:
   - Enter your domain (e.g. `qbonic.com` or `www.qbonic.com`).
   - Enable **Enforce HTTPS**.
5. Your site will be live instantly!
