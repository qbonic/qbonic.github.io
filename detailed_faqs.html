🛡️ 1. Core Data Privacy & Zero-Server-Upload Architecture Zero Cloud Retention

🛡️
Where does my spreadsheet data go? Does Qbonic upload files to any server? 100% In-Browser RAM

100% in-browser processing. Raw CSV, TSV, and Excel data is parsed directly inside your device's local memory (RAM / Web Workers). Zero raw spreadsheet cell values or customer records are ever uploaded to remote servers or third-party cloud databases.

✨
Client-Side Isolation Guarantee

Your datasets exist exclusively within your browser sandbox. Even if our servers are completely offline, your data pivoting and formula calculations function seamlessly.

🔒
Does Qbonic, its developers, or any backend server ever store or cache my sales data? Zero Data Storage

No. We operate on a strict Zero-Data Architecture. We have no database tables, object storage buckets (S3/GCS), or caching layers capable of holding your spreadsheet rows.

🔍
How can I verify that my data never leaves my browser? Auditable in DevTools

You can independently verify this in seconds: open your browser Developer Tools (F12 or Cmd+Option+I) → Network tab while loading files and pivoting data. You will observe zero file payloads or raw cell data uploaded over the network.

📄
When I connect a Google Sheet via URL, does Qbonic proxy it through a server? Direct HTTPS Fetch

No. Your browser makes a direct client-side HTTPS fetch to Google's public CSV export endpoint. Qbonic's servers never touch the connection, inspect the headers, or proxy the stream.

⚡
What happens to my data in memory when I close the browser tab? Instantly Garbage-Collected

All in-memory parsed rows are immediately wiped and garbage-collected by your browser's JavaScript V8/WebKit runtime engine. Zero unencrypted traces remain in device memory.

🛡️
Are any third-party CDNs or scripts able to read my in-memory dataset? Isolated Scope

No. Qbonic executes in an isolated client-side React scope. We do not load third-party ad trackers, tag managers, or invasive session-replay scripts (like FullStory or Hotjar) that could capture DOM text.

📊
Can Qbonic see the content of my pivot cubes, charts, or generated dashboard summaries? Local DOM Rendering

No. All aggregation sums, sparkline trends, KPI formula results, and pivot table cells are calculated and rendered locally in your browser's Document Object Model (DOM).

🤖 2. AI Classification & Groq API Key Security Metadata-Only Isolation

🤖
Does AI (Groq) see my actual customer rows, sales numbers, or private data? Zero Row Upload

No. Groq AI only receives high-level column metadata to suggest smart classifications and formulas. Your full dataset, customer tables, and financial records are never uploaded or shared with external AI servers.

✅ Sent for AI Suggestions
  • • Column header names (e.g. "Order Date", "ARR")
  • • Inferred column data types (e.g. Number, Date)
  • • Distinct value counts & up to 3 anonymized samples
❌ Strictly Never Shared
  • • Raw customer rows and PII
  • • Financial numbers & transaction records
  • • Complete spreadsheet tables
⚡
Can I use Qbonic without creating a Groq AI account or entering an API key? 100% Optional

Absolutely. Qbonic includes an intelligent built-in rule heuristics engine that works out of the box with zero API key or external account required.

Because spreadsheets vary across business domains, automated classifications (both rule-based and AI) serve as smart starting points. We recommend reviewing the interactive Configuration page to fine-tune column types, unit formats (Currency, %, Count), and custom KPI formulas for your exact use case.

🔑
Where is my Groq API Key stored? Local Storage Only

Your Groq API key is stored exclusively in your browser's private localStorage (key: qbonic_groq_api_key). It is never transmitted to Qbonic servers, telemetry endpoints, or third-party loggers.

🛡️
Does Groq use my column headers to train foundational models? Zero Model Training

No. Under Groq's Commercial API terms of service, data submitted via their inference endpoints is processed strictly in volatile GPU memory and is never used to train foundational AI models.

🗑️
How can I delete or rotate my Groq API Key? 1-Click Local Purge

Navigate to Settings → AI Configuration and click "Remove Key". It is immediately purged from your browser storage with zero residual backups.

⚖️ 3. Regulatory & Legal Compliance (GDPR, CCPA, HIPAA) Privacy by Design

⚖️
Is Qbonic compliant with GDPR (Europe) and CCPA (US)? Article 25 Compliant

Yes. Qbonic is engineered on strict "Privacy-by-Design and by Default" principles (GDPR Article 25). Because raw dataset rows never leave your computer, there is zero persistent cloud data retention and zero cross-site behavioral tracking.

🏥
Can healthcare teams safely analyze clinical data on Qbonic under HIPAA? Zero PHI Transmission

Because computation occurs entirely on the user's local hardware without transmitting Protected Health Information (PHI) to cloud servers, Qbonic supports secure in-browser healthcare data exploration without breaching HIPAA server storage rules.

📝
How does Qbonic handle GDPR "Right to be Forgotten" (Data Erasure)? 30-Day SLA

You can request permanent account deletion at any time by emailing admin@qbonic.com. All authentication profile metadata in Firestore is wiped within 30 days. No raw dataset rows exist on our servers to erase.

🍪
Does Qbonic use third-party advertising cookies or cross-site tracking pixels? Zero Ad Trackers

No. We do not use Meta Pixel, Google Ads remarketing pixels, or third-party behavioral advertising cookies. Your analytical workflow is completely private.

📊 4. Product Usage Telemetry & Error Logging Pseudonymous Logging

📊
What telemetry does Qbonic collect? Operational Events

We collect lightweight milestone event logs: event name (e.g. DATASET_LOADED, REPORT_SAVED), pseudonymous User_UID, device type, browser, screen resolution, and unhandled error stack traces for application reliability.

🆔
Why does Qbonic use a pseudonymous User_UID instead of email? PII De-Identification

In accordance with GDPR Article 25 (Privacy by Design), using pseudonymous business IDs (e.g., SHP1000001 or guest session hash) prevents Personally Identifiable Information (PII) like email addresses from proliferating into operational telemetry logs.

🛡️
Does product telemetry ever log cell values or financial numbers? Strictly Zero

Strictly zero. Telemetry only captures high-level structural counts (e.g., row count tier 10K-30K, total dimensions 4). Specific cell values, column contents, and financial amounts are never captured.

Persistent Local Templates
